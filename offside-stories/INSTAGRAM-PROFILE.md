# Offside Stories: Instagram profile kit (@offsi.des)

Paste these in Instagram → Edit profile. Instagram has no API for editing a bio, so these are copy-paste.

## Name field (searchable, max 64)
**Offside Stories | Football Docs**

The name field is indexed by search; the bio is not. Your handle `offsi.des` is hard to type and remember, so the name field does the search work.
Note: **@offside.stories** (an active Israeli football-culture page) and **@offsidestories** (a dormant 2018 football page) already use this name. Searches for "Offside Stories" will show them too.

## Account settings
- **Account type: Creator, not Business.** Business accounts only get Instagram's royalty-free "Sound Collection"; Creator accounts keep the much larger music library you'll want when adding music to Reels. (Settings → Account type and tools → Switch to professional → Creator.)
- **Category:** Digital creator (or "Media/news company" if you later run it as a business).
- **Profile picture:** `offside-stories-profile-picture.png` (the O|S mark: S stepping past the offside line). Built to survive the small circle crop.
- **Link:** leave empty until you have somewhere worth sending people (a YouTube channel for longer cuts, for example). An empty link beats a dead one.
- **Contact options:** add a public email if you want collab/brand enquiries.

## Highlights (add once you have 3+ episodes)
Episodes · Underdogs · Records · Legends. Covers: black circle, one yellow word in League Gothic, same as the Reel titles.

## Posting Episode 001
1. Upload `offside-stories-ep001-jamie-vardy-en.mp4` (or the music version once it exists).
2. Cover: upload `offside-stories-ep001-cover.png` ("Add from camera roll" on the cover screen). Its key text sits inside the 3:4 grid crop.
3. Caption: `CAPTION.md`.
4. Music: if you add a track in Instagram, keep it at roughly 15–25% volume so the narration stays clear, and start it on a strong section, not a quiet intro.
5. Pin it to the top of the grid. Turn on "Also share to Facebook" only if you're running a Facebook page too.

## Every episode, same treatment
Black ground, white League Gothic headlines, electric yellow (#FFE600) for the one word that matters, red (#E10600) only for stamps like "Released" or "Record broken", word-by-word subtitles, and the OFFSIDE|E sign-off in the last 4 seconds.
